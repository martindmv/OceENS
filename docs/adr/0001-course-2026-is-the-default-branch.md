# `course-2026` becomes the default branch during the semester

For the *Complex Web Services* 2026–27 course, about twenty students fork OcéEns, and a fork starts from the default branch. `course-2026` therefore becomes the repository's default branch: forks start from it and pull requests target it (the development sign-in, #82, and the per-role seed, #84, among them). `main` is not touched during the semester, to give students a stable base and to keep course-specific code out of it; no `main` → `course-2026` synchronisation is planned before the end of the semester.
